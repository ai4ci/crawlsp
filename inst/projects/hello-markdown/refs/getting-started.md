# Getting Started

Welcome to the hello-markdown project. This page covers installation
and basic configuration.

See the [README](../test-readme.md) for a project overview.

## Prerequisites

- A markdown-aware editor or viewer
- No dependencies beyond a file system

## Installation

1. Clone or copy the project directory.
2. Open [README.md](test-readme.md) in your editor.
3. Follow the links to explore the documentation.

## First Steps

Once you have the files open, start with the
[API Reference](./api.md) to understand the available functions,
then browse the [Examples](./examples.md) to see them in use.
