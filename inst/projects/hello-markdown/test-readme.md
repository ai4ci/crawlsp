# Hello Markdown

A toy documentation project used to test markdown language server support.

## Overview

This project demonstrates a small interlinked set of markdown files.
Each document links to at least one other, forming a graph that can be
crawled and indexed.

## About

The project has no real functionality. Its only purpose is to provide
a realistic multi-file markdown structure for LSP testing.
